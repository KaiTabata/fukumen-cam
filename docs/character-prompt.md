# キャラの画像を画像生成 AI で作る

プロンプト・画像の条件・取り込み方法は、設定画面の「**キャラの登録**」にまとまっています。
各プロンプトには「コピー」ボタンがあり、日本語版と英語版を切り替えられます。文面は [`web/prompts.js`](../web/prompts.js) で管理しています。

## 表情シートでまとめて作る（おすすめ）

全表情を 1 回で描いてもらうプロンプトをコピーし、できた画像をその下の枠にドロップすると、コマを自動で切り分けて表の各マスに入れます（`web/sheet.js`）。

| シートの形 | 中身 |
|---|---|
| 2枚に分ける（高画質） | シートA：通常・笑顔・ドヤ顔・驚き／シートB：困り・怒り・考え中・ウインク。各 4列×2段（上の段＝口を閉じた、下の段＝口を開けた）。シートB はシートA を添付して頼むとキャラがそろう |
| 1枚にまとめる（手軽） | 4列×4段の16コマ。1〜2段目がシートA、3〜4段目がシートB と同じ並び |

切り分けは、背景の緑の「すき間」を探して区切るので、コマの間隔が多少ずれていても大丈夫です。切り出したキャラは足元と体の中心をそろえて置き直します。

## 参考にするキャラ・絵柄

「参考にするキャラ・絵柄」に書いた内容が、プロンプトの「〜にそっくりな見た目で」の部分に入ります。空欄のときは、オリジナルの青いちびキャラのプロンプトになります。他人が権利を持つキャラクターに似せた画像は、私的に楽しむ範囲で使ってください。

## 写真の人物をキャラにする

「キャラの元」を「写真の人物をデフォルメ」にすると、添付した人物写真をデフォルメするプロンプトになります。髪型・メガネなどの特徴は残し、絵柄・頭身・服装・ポーズは指定した絵柄に合わせます。写真の本人に了解をとってから使ってください。

## 1 枚ずつ作る場合

1. 「最初の4枚」の①をコピーして画像生成 AI に貼る
2. できた①の画像を添付して、②「口を大きく開けた顔」を作ってもらう（③半開き・④目を閉じた顔は任意）
3. 表情を増やすときは「表情：〜」を選び、①を添付して「口を閉じた」版 → それを添付して「口を開けた」版の順に作る
4. 表のマスに入れるか、ファイル名を付けて（例: `smile_open.png`、`驚き_閉.png`）まとめてドロップする

## 画像の条件

- PNG（透過可）/ JPEG / WebP、1枚 20MB まで
- 縦長（3:4 か 2:3）、1200×1600 程度
- 全枚数で画像サイズ・キャラの位置・大きさをそろえる（ずれると口パクのたびに絵が動く）
- 背景は真緑（#00FF00）の単色か透過PNG（単色背景は自動で透過）
- 全身が入り、足元が画像の下端近く。文字・ロゴ・枠なし
